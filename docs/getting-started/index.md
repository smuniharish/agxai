# Getting started

Three steps, from install to a first explained decision. None of them needs an
external service.

<div class="grid cards" markdown>

-   :material-download:{ .lg .middle } __[Installation](installation.md)__

    ---

    Install the core, or add the LangGraph extra and any observability
    provider you use.

-   :material-rocket-launch:{ .lg .middle } __[Quickstart](quickstart.md)__

    ---

    Instrument a fraud-review graph, record its evidence and decision, and
    explain that decision to an auditor.

-   :material-tune:{ .lg .middle } __[Configuration](configuration.md)__

    ---

    Set the capture mode, failure mode, redaction and providers for each
    runtime, in code.

</div>

After the quickstart, the [User guide](../guide/index.md) explains each record
type and walks through common tasks.
